# Video Reference Board · AI 视频生成辅助参考板

> 参考样图：[video-reference-board-sample.png](video-reference-board-sample.png)（"MV小提琴演奏场景・分镜脚本与美术设计方案"）

## 这是什么图

不是封面，不是海报，不是信息图。这是一张**电影预制作（pre-production）的综合视觉契约**——把角色、场景、分镜、机位、灯光、调性所有视觉决策压缩到一张图里，让 AI 视频模型（即梦 / Sora / Veo / Runway / 可灵）能：

- 看到角色的多视角（保证视频里不变脸、不变服装）
- 理解场景的空间关系（机位移动有依据）
- 知道每个镜头的节奏（时长、运动方式、景深）
- 锁定光影氛围（不同光源参考给到）

**核心隐喻**：这就是好莱坞的 art bible / shot list 在 AI 时代的对应物。模型把它当作一份"片场执行手册"来读。

---

## 为什么是"一张图"而不是分多张

把这一切压成一张图，有三个特殊价值：

1. **作为 image-to-video 的输入**：很多视频模型（即梦、Runway）首选图生视频，单图比多图描述更稳定。模型从这张图同时获得**外观一致性参考**和**镜头语言提示**。
2. **作为 ChatGPT / Claude 的视觉对话基底**：拍摄者把这张图发给 LLM 让它写 prompt，模型一次性"看懂"整个项目。
3. **作为团队对齐物料**：写脚本/对接美术/沟通客户都用同一张图，不会丢信息。

## 9 组件构成（前 8 必给，第 9 强烈建议）

| # | 组件 | 作用 | 在画面中的位置 |
|---|---|---|---|
| 1 | **顶部标题区** | 项目名 · 类型说明 | 顶部居中 |
| 2 | **角色参考图（造型方案）** | 6 视角：正/侧/背 全身 + 正/侧/背 特写 | 上方左半幅 |
| 3 | **场景空间图** | 平面图（俯视）+ 正立面图 ×2 + 剖面图 | 上方右半幅 |
| 4 | **机位与场景特点文字框** | 列出机位 ①②③④ + 场景调性 5 条 | 场景图右侧 |
| 5 | **分镜脚本** | 3-4 个关键镜头，每个含画面+时长+机位设置 | 中部并列 |
| 6 | **镜头运动流程示意** | 4 步骤的小图标 + 缩略图，箭头连接 | 分镜右侧 |
| 7 | **灯光参考图** | 4 种光源的实拍/AI 缩略图 | 底部左侧 |
| 8 | **导演要点 + 推荐镜头与色调** | 整体调性、焦段、对比度、质感总结 | 底部右侧 |
| 9 | **色彩与氛围参考色卡**（强烈建议）| 4 色色板 + 主色/辅色/基调/氛围标签 | 场景空间图下方或右侧 |

**红线**：前 8 不要少给。少了角色三视图 → AI 视频模型保持不住一致性；少了平面图 → 镜头空间感乱；少了灯光 → 氛围漂移。

**关于第 9 组件**：模型有时会自发贡献色卡（实测江南琵琶 MV 案例就是模型主动加的），但**显式要求更稳定**。色卡对后续 image-to-video 流程价值大——视频模型在调色一致性上有色卡参考会显著好于无参考。

## 4 条核心原则

### 原则 1 · 信息密度优先（每一格都在打包决策）

参考板不能"留白当呼吸"——每一块区域都要传达信息。判断标准：

- ✅ 角色三视图：每张都换姿态/表情，不只是机位转动
- ✅ 场景图：平面图必须标机位编号，不是单纯室内效果图
- ✅ 分镜：每镜头必含「焦段/高度/运动/景深」四参数

### 原则 2 · 多视角一致性是头号目标

角色三视图（character turnaround sheet）是给 AI 视频模型保持一致性用的。**6 张是经过验证的最小集**：少于 6 张模型容易在反打镜头时失真。

**三视图标准**：
- 正面 / 侧面 / 背面 全身（提供轮廓信息）
- 正面 / 侧面 / 背面 特写（提供面部 + 服装细节信息）

### 原则 3 · 时空解构（4D → 2D）

视频是 4 维（XYZ + 时间），参考板是 2 维。**关键是把 4D 信息分类编码到 2D 平面里**：

| 信息维度 | 编码方式 |
|---|---|
| 三维空间 | 平面图（俯视）+ 正立面图（多角度）+ 剖面图 |
| 机位空间分布 | 平面图上标 ①②③④ 圆形数字 |
| 时间序列 | 分镜脚本横向并列（左→右 = 早→晚） |
| 镜头运动 | 流程图 + 箭头 |
| 时长 | 每分镜右上角"时长约 X~X 秒" |

### 原则 4 · 排版传统不能丢

这种参考板的"专业感"来自电影行业 50 年的视觉传统：

- **深色背景**（黑色 / 深褐色）+ 米黄色 / 浅米色信息层（致敬旧时电影排版）
- **圆形数字标号**（①②③④）—— art bible 标准
- **细黑体中文标题** + **细体说明文字**
- **虚线箭头连接**机位与镜头
- **每一区域都有标签框**（"角色参考图（造型设计方案）" 这种带括号副标题）

**反 default 警告**：模型默认会把这种图做成"现代信息图"风格（蓝色渐变、扁平图标）。**必须显式锚定"电影分镜脚本传统排版"**才能拿到正确风格。

## 标准 prompt 模板（中文 · ≤ 200 字）

参考板属于「technical infographic 含具体结构」例外，可放宽到 200 字内。模板按 8 组件骨架填空：

```
[场景名] · 分镜脚本与美术设计方案 · 综合参考板。
顶部标题分两栏副标题（左：角色设定·服装造型；右：美术设定·场景与道具）。
画面分四区：
① 上左·角色参考图 6 视角（正/侧/背全身 + 正/侧/背特写），主角 [年龄性别+服装造型一句话]；
② 上右·美术设定，含平面俯视图 + 正立面图×2 + 剖面图，平面图上标机位 ①②③④，
右侧文字框列场景特点 5 条 + 色彩与氛围参考色卡（4 色色板 + 主色/辅色/基调/氛围标签）；
③ 中部·分镜脚本 3 镜头并列，每镜头给画面 + 时长 + 焦段/高度/运动/景深；右侧画镜头运动流程 4 步示意图；
④ 底部·灯光参考 4 张缩略图 + 导演要点 + 推荐镜头与色调文字框。
风格：电影分镜脚本传统排版，深色背景 + 米黄信息层 + 圆形数字标号 + 虚线箭头。
全部描述性文字用中文。比例 16:9，1920×1080。
```

**填空清单**（在 [] 处替换）：
- 场景名（如「江南古风琵琶独奏MV」）
- 主角造型一句话（如「20 岁古风少女，月白襦裙 + 高发髻，怀抱琵琶」）
- 场景特点 5 条（如「江南园林 / 月夜 / 圆窗洞门 / 太湖石 / 灯笼烛光」）

## 实战示例 prompt（江南古风琵琶独奏 MV）

```
江南古风琵琶独奏 MV · 分镜脚本与美术设计方案 · 综合参考板。
顶部标题分两栏副标题（左：角色设定·服装造型设计为拍摄提供依据；右：美术设定·场景参考图与道具设定）。
画面分四区：
① 上左·角色参考图（造型设计方案），6 视角：正/侧/背 全身 + 正/侧/背 特写。
主角是 20 岁古风少女，月白色齐胸襦裙、外罩浅青纱衫，乌发高髻配步摇，怀抱琵琶；
② 上右·美术设定参考（场景：江南园林月夜），含平面俯视图（标机位 ①②③④）、
正立面图（南向、东向）×2、剖面图 A-A'。右侧文字框「场景特点」列：
苏式园林回廊 · 圆形月洞门 · 太湖石假山 · 池塘睡莲 · 红灯笼与烛台点缀；
下方「色彩与氛围参考」色卡 4 色（主色冷蓝月色 · 辅色灯笼暖红 · 基调静谧清幽 · 氛围古典诗意）；
③ 中部·分镜脚本 3 镜头并列：
镜头 1「侧面中景（弹奏起势）7~8 秒，35mm 定焦，与琵琶平视，缓慢推镜，中景深」；
镜头 2「琵琶弦指特写 4~5 秒，85~135mm，琴弦平视，静止微推，浅景深」；
镜头 3「斜侧面情绪特写 4~5 秒，85~135mm，略高于眼平，轻微横移，浅景深」。
右侧画镜头运动流程 4 步示意图（机位简笔图 + 缩略画面 + 黄色箭头连接）；
④ 底部·灯光参考 4 张缩略图（月光透窗 / 灯笼暖光 / 烛台围光 / 补光柔光），
配「导演要点」文字框（整体冷暖对比·演奏与节奏呼应·克制运镜）+
「推荐镜头与色调」文字框（35mm/85mm/135mm 定焦 · 暖色调电影感 · 浅对比·古典质感）。
风格：电影分镜脚本传统排版，深色背景 + 米黄信息层 + 圆形数字标号 + 虚线箭头连接。
全部描述性文字用中文。比例 16:9，1920×1080。
```

约 480 字（含格式说明），实际语义浓度高。如果模型对长 prompt 处理不稳，可以拆成两步：先给前半（角色 + 场景），生成后参考它再给后半（分镜 + 灯光）。

## 常见踩坑

| 症状 | 原因 | 解法 |
|---|---|---|
| 输出像现代 dashboard 风（蓝色 + 扁平 icon） | 模型默认偏向"信息图"训练数据 | 显式写「电影分镜脚本传统排版 + 深色背景 + 米黄信息层」 |
| 角色三视图变成同一个角度六张 | prompt 没强调"换视角" | 写明「6 视角：正/侧/背全身 + 正/侧/背特写」 |
| 平面图没标机位 | 平面图变成纯装饰 | 写明「平面图上标机位 ①②③④（圆形数字）」 |
| 分镜画面看不出区别 | 没说每镜头的差异 | 每个分镜单独给焦段/高度/运动一句话 |
| 文字英文了 | 训练数据偏见 | 显式写「全部描述性文字用中文」 |
| 信息密度太低，留白多 | 没列具体子项数量 | 给数量约束（场景特点 5 条 / 灯光 4 张） |

## 与已有 skill 的边界

- **本文档** 处理「综合视觉参考板」这一类——多视角 + 多组件 + 元数据。
- **single-image-playbook.md** 处理普通单图（封面 / 海报 / 包装 / 信息图）。
- **prompt-patterns.md** 处理批量生成（icon集 / 角色集 / 卡牌集）。
- **huashu-video-director / ai-video-prompt** 处理"用文字 prompt 直接生视频"——本参考板是它们的**前置物料**，不是替代品。

**典型工作流**：
1. 用本模板生成视频参考板（GPT-image-2）
2. 把参考板交给 huashu-video-director / ai-video-prompt，让它结合参考板写出每个镜头的视频 prompt
3. 把单镜头 prompt + 参考板（image-to-video 输入）丢给即梦 / Veo 生成视频片段
4. 拼接成片

## 实战案例 · 江南古风琵琶 MV（2026-05-03）

第一次按本方法论出图就达到可交付水平，详见 [video-reference-board-success-pipa.png](video-reference-board-success-pipa.png)。

**关键观察**

| 维度 | 结果 |
|---|---|
| 8 组件完整度 | ✅ 全部命中 |
| 中文文字准确率 | 99%（仅 1 个错字：「造型」→「造塑」）|
| 自发贡献组件 | ✅ 模型主动加了「色彩与氛围参考」色卡（4 色 + 主色/辅色/基调/氛围标签）|
| 风格匹配 | 模型把角色三视图从"真人摄影感"调整为"工笔画/CG 古风"，是合理的载体匹配（古风题材 → 工笔风格更契合）|
| 平面图风格 | 偏「俯视游戏地图」感而非建筑施工图——古风题材的自然延伸，不是错误 |

**复用经验**

1. **色卡是高价值组件**：模型自发会加，但显式要求更稳定。已加入第 9 组件 + 模板 prompt。
2. **风格自适应是好事**：原图模板基于真人摄影 MV，模型会根据题材自动调整渲染风格（古风 → 工笔），不要强制统一。
3. **错字是字符级问题**：22 字符正确率 ≈ 95-99%，复杂偏旁（如「型」）偶有失真——验收时人工扫一遍标题级文字即可，不需要重新出图。
4. **角色三视图独立框非常好用**：模型把「造型要点」单独成框列 5 条要点，比塞进角色描述更清晰，建议在模板中显式要求。

**改进方向（下次试）**

- 让模型自己选「真人摄影 vs 工笔画 vs 油画感」之一，先说理由再上图
- 若想刻意拿到"真人摄影感"参考板，需在 prompt 中显式锚定（如「8K 写实摄影质感，参考杨幂《风起霓裳》剧照」）
- 平面图想要"建筑施工图风"，可在 prompt 加「平面俯视图采用工程化施工图绘制风格，不是游戏俯视场景图」
