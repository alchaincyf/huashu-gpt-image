# Single-Image Playbook · GPT-image-2 单图生成完整方法论

> 这是基于 2026-04-30 与花叔的真实测试积累的认知。覆盖任何单张 AI 图片生成场景：公众号头图、小红书封面、B站/YouTube 封面与 banner、产品包装、海报、信息图、UI mockup、slides、配图。
>
> 核心心法一句话：**当模型足够强时，prompt 工程的瓶颈从「描述能力」转向「概念库储备」**。脑子里有多少精准设计师/品牌/工作室名字，决定 prompt 上限。

---

## 第一性原则：概念压缩比

**Prompt 的有效信息 ≠ prompt 的字数。决定输出质量的是单字承载的设计决策密度。**

实测案例：「Dieter Rams 风格的大疆 pocket3 说明书」16 个字 → 拿到完整 A4 说明书，含真实参数（1英寸 CMOS / 4K120fps / 139.7×42.2×33.5mm），视觉精度达到官方手册级别。

原因拆解：每个词都是高密度语义锚点：

| 词 | 打包了多少决策 |
|---|---|
| Dieter Rams 风格 | 几百条决策（色彩极简 / Braun 灰白红 / 等线无衬线 / 严谨网格 / functional clarity 哲学） |
| 大疆 | 品牌识别 + 官方文档美学 + 中英混排习惯 |
| pocket3 | 真实产品参数（模型有训练数据） |
| 说明书 | A4 排版 / 章节编号 / 规格表 / 部件标注的全套范式 |

**实操**：写 prompt 之前先问——「主体 / 风格 / 媒介」三个槽位，能不能各填一个模型熟知的高频名字？能 → 16 字 prompt 就够。不能 → 哪个槽位填不上，那个槽位必须用结构化描述补足。

## 三种工作模式（按你心里有什么选）

| 模式 | 你心里有 | Prompt 形态 | 适合 |
|---|---|---|---|
| **执行** | 清晰的目标和参考 | 三层全给（上下文 + 约束 + 表面层完整） | 商单 / 品牌物料 / 已定 spec 的项目 |
| **混合** | 方向但不定细节 | 上下文 + "不要什么"，表面层留白 | 日常大部分情况 |
| **探索** | 一个问题，没答案 | 只给上下文 + 防 slop + 要求模型先说判断 | 想看惊喜 / 找新方向 |

**判断节奏**：
- 不确定走什么风格 → 先用探索模式开 5-10 张看方向
- 挑出最让你心动的方向 → 切到执行模式深化、批量、保稳定
- 不要一上来就执行模式（会把模型按在「执行你的设计」位置，错过它能贡献的判断）

## 三层指令架构

任何创意任务都按这个分层构造 prompt：

1. **上下文层**：who（观众）/ why（解决什么问题）/ for what（看完做什么）。这是 GPS 坐标。
2. **约束层**：必须 / 禁止 / 冲突时的优先级。这是边界条件。
3. **表面层**：媒介 / 风格 / 参考 / 技术参数 / 色值字体。这是结果形态。

业余 prompt 只写第 3 层（"一张赛博朋克风格的海报"）。专业 prompt 三层都给。

## 三维质量模型（conceptual blending 成败的真公式）

```
输出质量 = 载体匹配度 × 精神理解深度 × 创造贡献空间
```

### 维度 1 · 载体匹配度

风格的「**原生载体**」和你的「**目标载体**」是否同一类型。

| 风格 | 原生载体 | 适配的目标 | 不适配的目标 |
|---|---|---|---|
| Helvetica | 排版系统 | 菜单 / 标识 / 文档 | 三维产品包装 |
| Dieter Rams | 工业产品 | 包装 / 设备 / 家电 | 表格 / 价目表 |
| Brutalism | 建筑空间 | 包装（三维实体）/ 海报 | 数字 UI |
| The Criterion Collection | 收藏品出版 | 产品页 / 手册 / 海报 | 食品包装 |
| Penguin Books | 书籍封面 | 手册 / 书籍 / 三段式构图 | 三维产品 |

实操：选风格之前先想——这风格的设计师本来在设计什么？你的目标和那个本来的载体是不是同类？

### 维度 2 · 精神理解深度

模型对风格「是什么」的理解深度（与训练数据相关）：

- **深度高**（设计史教科书级别概念）：Bauhaus / Brutalism / Dieter Rams / Helvetica / Swiss International Style
- **深度中**（高频但偏视觉呈现）：Wes Anderson / Field Notes / The New Yorker
- **深度浅**（停在表层标签）：小众设计师 / 非西方设计运动 / 时代+地域组合

实操：表层（如 Wes Anderson 的 deadpan melancholy）→ prompt 必须补结构化描述；精神层（如 Brutalism 的 truth to materials）→ 可以放手。

### 维度 3 · 创造贡献空间

目标载体允不允许模型做品牌命名 / slogan 创作 / 结构隐喻。

- **空间大**：包装（要品牌名）/ 海报（要 headline）/ 书封（要 series 名）→ 模型可贡献「禾筑」「本原」这种惊喜
- **空间小**：菜单（菜名给定）/ 价目表（药材名固定）/ 个人简介（信息固定）→ 只能在视觉层发挥

## 风格的「结构性 vs 气质性」二分（关键）

这是 conceptual blending 成败的核心二分。

### 结构性强的风格（模型能精准 transfer）

特征：可枚举的视觉元素（色彩 / 字体 / 构图 / 编号 / 装饰），元素是「模块化」的，可拆下来安装到新主体上。

代表：Penguin Books / The Criterion Collection / Dieter Rams / Field Notes / Massimo Vignelli / Bauhaus / MUJI

**短 prompt 即可拿到 9 分以上**。

### 气质性强的风格（模型只能抓表层）

特征：核心是「难以言传的氛围」，模型只能复制标签式特征（粉绿色对称代表 Wes Anderson），抓不到精神（deadpan + melancholy）。

代表：Wes Anderson / 王家卫 / Tarkovsky / 老上海月份牌 / 日本浮世绘

**必须补结构化描述 + 给模型多个具体作品参考**。

## 概念库（你脑子里必须储备的名字）

按可 transferable 程度排：

### 第一梯队 · 结构最强，几乎必 work

- **Penguin Books**（橙/米/黑三段式 + 版本注释系统 + MODERN [X] CLASSICS 命名传统）
- **The Criterion Collection**（NO. 编号 + manifesto + critic quote + curated stamp）
- **Field Notes**（手账 + 印章 + 季节版本编号）
- **Dieter Rams / Braun**（极简 + 功能 hierarchy + 灰白红）
- **Massimo Vignelli**（NYC Subway 那套 + Modernist grid + Helvetica）
- **MUJI**（无品牌 + 牛皮纸 + 极简产品摄影 + 小字 spec）

### 第二梯队 · 结构中等，需要少量补充

- **Pentagram**（设计工作室，case 多但风格多样）
- **Phaidon / Taschen**（艺术出版品视觉）
- **The New Yorker**（杂志封面 + 衬线 + 单插画）
- **Wallpaper\* / Monocle**（生活方式杂志）
- **National Geographic**（黄框 + 摄影叙事）
- **Bauhaus / Swiss International Style**（几何 + 原色，但容易和邻近概念串台）
- **Anthropic**（赤陶橙 + 黑线条 + 学术克制）
- **Stripe**（紫蓝渐变 + 干净 grid + Sohne 字体）

### 第三梯队 · 气质性强，独立用风险大

- **Wes Anderson / Jacques Tati / 王家卫**（影像气质）
- **Tarkovsky / Bergman**（沉郁电影感）
- **老上海月份牌 / 日本浮世绘 / Art Nouveau**（强地域 + 强时代气质）

### 中文设计语境（模型理解度不一）

实测可用：MUJI 风格 / 无印良品风格 / 日式杂志风 / 朱赢椿装帧（部分）/ 靳与刘工作室
不要轻信：模糊的"中国风" / "国潮"（这些词模型会输出非常套路化的红色金色大字）

## 关键 Prompt 模式

### 模式 1 · Conceptual Blending（跨界混搭）

格式：`[Style] 风格的 [Subject] [Medium]`

适用：三槽位都是模型熟知的高频概念。

实测：
- ✅ 「Dieter Rams 风格的大疆 pocket3 说明书」9.5 分
- ✅ 「Penguin Books 风格的 Cursor 产品手册」9.5 分
- ✅ 「The Criterion Collection 风格的 Cursor 产品页」9.5 分
- ❌ 「Dieter Rams 风格的中药铺价目表」8 分（载体不匹配——Rams 设计产品，价目表是表格）

### 模式 2 · Invite 命名贡献（关键升级）

当载体允许品牌命名时，主动 invite 模型贡献——**对照实验显示从 9 分升到 9.5 分，且输出从单图升级为完整品牌系统**。

模板：
```
[Style] 风格的 [Subject Category]。
请你也贡献：
- 一个嵌入风格精神的品牌名（中英文都给）
- 一句呼应风格哲学的 slogan
- 一段命名逻辑解释（为什么叫这个名字）
- 一个证明你理解风格本质的隐喻细节
```

实测案例：
- 「Brutalism 风格的婴儿米粉包装」→ 模型自发贡献「禾筑」品牌名（禾 + 筑双关）
- 「Apple 设计语言的中药包装 + invite 命名贡献」→ 模型贡献「本原 BENYUAN / 让身体回到本来的秩序」+ 完整命名逻辑 + 4 个品牌价值观图标 + 三种 SKU 规格（30/90/300mL）

意外发现：当 invite 命名时，模型会**自动构建多 SKU 产品线**（不是单一包装），输出从「一张图」升级为「完整品牌提案」。

### 模式 3 · 反对模型内置和谐倾向

模型遇到风格 vs 品类冲突时会自动妥协（Apple 中药会变温润，不是科学冷硬）。如果想要冲突感：

```
[Style] 风格的 [Category]。

注意：保留 [Style] 的 [核心精神] 不动摇，不要因为是 [Category] 就妥协化。
冲突时优先保留 [Style] 精神，让 [Category] 去适应。
我要的是「[Style] 公司做了 [Category]」，不是「[Category] 借鉴 [Style]」。
```

### 模式 4 · 强制减法

模型默认会把所有好 idea 都塞进去（"more"在训练数据里被奖励）。强制减法解决"过满"问题：

```
出图前先做这件事：
1. 列出你想放进画面的所有元素（至少 8 个）
2. 砍掉 50%，只留 4 个
3. 说明「为什么留下的比砍掉的更有信息量」
4. 再生成
砍的标准：删掉之后画面信息没有损失，就该删。
```

### 模式 5 · 陷阱预警

让模型先识别这个方向最容易踩的刻板印象陷阱（用模型的元认知做品位防御）：

```
在生成之前先回答：
- 「[这个方向]」最容易踩的 3 个刻板印象陷阱是什么？
（例：复古杂志容易滑向"刻意复古的视觉梗"如"真香"印章）
- 你打算怎么避开？
```

### 模式 6 · 真实性细节锚点

```
画面里必须包含至少一个「具体到不能再具体」的真实细节：
- 一个真实存在的版本号（如 Cursor 0.42.3）
- 一个具体日期（如 2026-04-12 14:32）
- 一个具体型号（如 MacBook Pro M3 14"）
- 一个真实价格（如 $20/mo）
让画面从"看起来像"变成"看起来是真发生过的"。
```

### 模式 7 · 探索模式（找方向用）

```
任务：[简单描述]

上下文：[who / why / for what]

只有两条硬限制：
- 别做 AI cliché（齿轮/电路/大脑/紫渐变/赛博）
- [其他平台硬限制]

剩下的全部交给你。我想看你怎么判断这几件事：
- 这个情绪在视觉上最准的传达方式是什么？
- 这种内容放在哪个文化语境的美学里最合适？
- 字体、色调、构图你怎么决定？

给我 3 个差异化方向（不是 3 个版本），每个方向先用一句话说清你的判断逻辑，再上图。
我想看你的判断，不要给我「安全的好看」。
```

## 平台尺寸速查（开 prompt 之前必查）

**这一条是硬底线**——平台尺寸不是「表面层」可放手的部分，错了图就废了。涉及具体平台时一定先核实：

| 平台 / 用途 | 比例 | 推荐像素 |
|---|---|---|
| 公众号文章首图 | 2.35 : 1 | **1410 × 600** |
| 公众号文章配图 | 不限 | 视场景，建议 1080 宽以上 |
| 小红书封面 | 3 : 4 | **1242 × 1660** |
| 小红书横版 | 4 : 3 | 1242 × 932 |
| YouTube 视频封面 | 16 : 9 | **1280 × 720** |
| YouTube banner | 16 : 9 | **2560 × 1440**（安全区 1546 × 423）|
| B站视频封面 | 16 : 10 | **1280 × 800** |
| B站直播封面 | 16 : 9 | 800 × 450 |
| 抖音视频封面 | 9 : 16 | **1080 × 1920** |
| Twitter / X 帖子图 | 16 : 9 或 1:1 | 1600 × 900 / 1080 × 1080 |
| 头图 banner（网页） | 视场景 | 1920 × 480 / 2560 × 600 |
| Slides / PPT | 16 : 9 | **1920 × 1080** |

**多端适配特别警告**（YouTube banner 这种）：
- 总画布 2560 × 1440
- 中央安全区 1546 × 423 是**任何设备都能看到的部分**，必须收纳所有核心信息
- 桌面/平板/TV 看到更多，但**安全区外的内容不能依赖**

## 单图生成的常见踩坑

| 踩坑 | 解法 |
|---|---|
| 不核实平台尺寸就开 prompt | 先 WebSearch 验证（公众号封面是 2.35:1 不是 1.8:1） |
| 相信模型给出的设计史细节（口号/年代/合作品牌） | 自己核实，模型会串台（Bauhaus 串到 Dieter Rams 的 "Less but better"） |
| 期待气质性风格被精准 transfer | 气质性风格补结构化描述 + 多个具体作品参考 |
| 让模型决定品牌名却不主动 invite | 明确写出"请你贡献品牌名 + slogan + 命名逻辑" |
| 一次性 prompt 期待完美 | 探索→挑方向→执行三段式 |
| 看到模型加了多余的"安全好看"元素 | 用「强制减法」模式，让模型自己砍 |
| 风格 vs 品类有冲突但模型自动和谐了 | 用「反对内置和谐」模式 |
| 写了一堆形容词描述风格 | 形容词换成 1 个真实参考名字 |
| 列了 3 个参考结果输出在三者中游移 | 改用 1 个最强参考 + NOT 列表 |

## 邻近概念串台警告（已知混淆对）

模型在训练语料里高度共现的概念会串台。引用具体细节时必须自己核实：

- 包豪斯 ↔ 瑞士国际主义（Müller-Brockmann）
- 包豪斯 ↔ Dieter Rams（"Less but better" 是 Rams 不是 Bauhaus）
- Pentagram ↔ Sagmeister（都是设计 superstar）
- 老上海 ↔ 民国年代 ↔ Art Deco
- Wes Anderson ↔ Jacques Tati（都对称 + 复古 + deadpan）
- The Criterion Collection ↔ MUBI（都是 curated cinema）
- 朱赢椿 ↔ 吕敬人（都是中国书籍装帧大师）

## 4 个高频场景的「真问题」对照（给 prompt 瞄准）

### 场景 1 · 海报 / 公众号封面

- **表面问题**：视觉风格
- **真问题**：信息等级 + 情绪反应（1 秒内传递核心信息 + 引发情感反应）
- Prompt 必交代：观众 / 3 秒后要记住什么 / 看完做什么动作 / 参考某海报家方法

### 场景 2 · App / Web UI 原型

- **表面问题**：UI 美观
- **真问题**：用户在这屏的决策成本
- Prompt 必交代：用户旅程位置 / 上一屏做了什么 / 这屏要解决的决策 / 品牌人格 / 竞品参照

### 场景 3 · 信息图

- **表面问题**：漂亮
- **真问题**：把复杂关系翻译成一眼可见的结构
- Prompt 必交代：关系类型（流程 / 对比 / 因果 / 层级）/ 最核心的"洞察" / 图表语言参考

### 场景 4 · 视频 / 动画封面 / 片头

- **表面问题**：画面好看
- **真问题**：节奏控制 + 信息时序
- Prompt 必交代：是片头 / 转场 / 收尾 / 情绪曲线 / 参考某种剪辑语言 / 单镜头时长意图

## 工作流（标准操作）

1. **判断模式**：清晰目标 → 执行；找方向 → 探索；多数日常 → 混合
2. **核实平台尺寸**：WebSearch 或查上面表格，不要凭记忆
3. **检查三槽位**：风格名 / 主体名 / 媒介名，能不能各填一个模型熟知的高频概念？
   - 三槽位都强 → 16 字 prompt 试一下
   - 有空槽 → 那个槽位补结构化描述
4. **若需要品牌叙事**：用 invite 命名贡献模式
5. **生成前**：让模型先做减法判断 + 陷阱预警
6. **生成后评分**：按三维质量模型评（载体匹配 / 精神理解 / 创造贡献）
7. **不满意时诊断哪一层错了**：上下文层错（情绪/受众判断）→ 重写上下文；表面层错（字体/色彩）→ 调表面；约束层错（slop 没防住）→ 加禁止项
8. **挑定方向后**：切执行模式深化和批量，保证稳定输出

## 关键认知收尾

**当 AI 图像模型足够强时，prompt 工程的瓶颈从「描述能力」转向「概念库储备」**。

你脑子里能调出来多少个精准的设计师名字、品牌名字、媒介范式名字，决定了你能压缩 prompt 的上限。

最值得长期投入的不是研究 prompt 技巧，是研究每个领域的真知识——读 Dieter Rams 的《Less and More》、读 Massimo Vignelli《Vignelli Canon》、看 The Criterion Collection 的封面合集、把 Penguin Books / Field Notes / MUJI 的视觉系统拆解清楚。这些名字沉淀进脑子里，prompt 自然就有锐度。
